# Handoff for UMG documentation

Handoff for UMG imports a design package into Widget Blueprints and re-imports after design changes without losing
your graphs or hand edits. Works with Figma design through the free companion exporter.

The pages marked *synced* are copied from the plugin's own `Docs/` folder by the release pipeline, so they always match
the shipped version.
