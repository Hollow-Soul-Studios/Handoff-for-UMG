# MainMenu v1 -> v2: M4 safe re-import scenario

Packages (`MainMenu_v1.zip`, `MainMenu_v2.zip`) are generated by the publisher's deterministic sample script. Both share `source.fileKey = SAMPLEKEY01`
and identical asset PNGs. Node ids are unchanged between versions except for the pasted `Panel`.

## Test script

1. Import `MainMenu_v1`. Add graph logic to `WBP_MainMenu` and BindWidget references to `Play`, `Quit`,
   `Title` and `Version`, plus one reference to `Ammo` on `WBP_HUD`.
2. In Unreal, change 3 properties by hand (suggested; the importer must keep these):
   * `Title`: font size (v2 changes it to 64 -> conflict)
   * `Version`: colour (v2 changes it -> conflict)
   * `Menu`: item spacing (v2 changes 16 -> 20 -> conflict)
3. Import `MainMenu_v2` over it.
