Handoff for UMG - Third-party notices
=====================================

1. The Unreal Engine plugin bundles no third-party code
-------------------------------------------------------
The modules under Source/ (HandoffCore, HandoffImporter, HandoffCommonUI) were written for this project and
contain no third-party source code, libraries or binary assets. The plugin depends only on Unreal Engine modules
and, optionally, the Common UI and Enhanced Input plugins that ship with the engine. Unreal Engine is subject to
its own license (Epic Games EULA).

The sample packages in Samples/ (MainMenu_v1.zip, MainMenu_v2.zip) are generated by the publisher's internal
sample script and contain only synthetic, procedurally drawn images.

2. Inspirations (no code used)
------------------------------
The following projects were studied for behaviour and ideas only. No source code from them was copied or adapted.
Details are in Docs/DesignLog.md.

  * Figma2UMG (https://github.com/Buvi-Games/figma2umg), MIT License - behaviour of component, variant and instance
    mapping and patch-style updates was studied.
  * UnityFigmaBridge (https://github.com/simonoliver/UnityFigmaBridge), MIT License - inspiration for components as
    prefabs, font download and re-applying user setup after a sync.
  * FigForge (https://github.com/havokentity/FigForge), MIT License - inspiration for the plugin + bridge
    architecture, per-axis anchors and deduplicated rasterisation.
  * Figma Converter for Unity (marketplace listing) - public feature list used as inspiration for scope.
  * benui / Unreal Garden articles on constructing widget trees in code - technique credited; implementation is
    independent.

If code from any of these projects is ever adapted, its copyright and license notice will be added here.

3. Fonts
--------
No font files are bundled. The optional "Download Google Font (OFL)" action is triggered by the user, fetches only
families that are published under the SIL Open Font License (the importer checks google/fonts ofl/<family>/OFL.txt
before downloading), and saves the font together with its OFL.txt. Downloaded fonts remain under their own license
(SIL OFL 1.1 and the copyright of each font's authors); the license text is kept next to the font files and the
imported font assets. Fonts you map yourself are subject to your own license for them.
